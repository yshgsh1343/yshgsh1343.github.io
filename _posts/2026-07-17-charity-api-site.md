如何开一个公益站？

1. 域名，免费二级域名就可以承担（虽然我用的自己的闲置）

2. 服务器，这个是最贵的，我自己认为保底是 4c8g 起步，我用的 do 学生包剩余赠金，0 元，但正价的话买 netcup 和 ovh 一月几十块。不知道龟壳能不能撬开咯，感觉 aws 那点赠金除非一月一抛吧。

3. 渠道，目前 grok 渠道相对好搞，grok2api 是很成熟的开源项目，注册机虽然总是批量死但也可以再注册（服务器好处尽显），其他渠道就是要考虑逆向能力，完全不会逆向的小白（比如我）在逆一个渠道需要反复和 ai 沟通，而这部分 api 基本都是要自费保证智商的，又几百块

4. 维护时间精力，我这种分发的尚且可以丢下不管，公益站是要真的确保注册用户可用性的，号池，渠道可用性，服务器炸没炸，都需要人来考虑
